## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Project Library** | Organize Krita painting projects with client and deadline info |
| **Brush Manager** | Track installed brush bundles with style and usage categories |
| **Reference Board** | Attach reference images and notes to active painting projects |
| **Commission Tracker** | Log commission status from sketch through to final delivery |
